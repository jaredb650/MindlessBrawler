# MEKA — sprite-sheet prompt pack

Every unsprited Meka animation, one fully copy-pasteable prompt each. Attach the
idle green-screen reference to every generation. Frame counts and layout are left
to the model — Opus cuts the sheets, you set fps in the tool. The only hard rules
baked into every prompt: flat green background, no frames touching, no labels.

The **mode table** at the bottom is the only tool setting that matters per sheet
(`once` = plays through and holds, `loop` = cycles).

---

## Tool modes (the only per-sheet setting that matters)

**loop** (cycles): downed, gassed, electrified, countered, clinch, clinched,
gpmount, gpmounted, sawgrabbed, execkneel, supercombo, magiccombo

**once** (plays through, holds last frame): everything else.

Air attacks (`airpunch, jumpkick, divekick, superman, flyknee, flyuppercut`) are
`once` on purpose — the last cell is the held flight pose for however long the
fall lasts. Set fps by feel per sheet; cells × 60 ÷ fps = how many game-frames
the sheet spans, if you ever want to match a move's timing exactly.
